# waleedawad.com

Personal software engineering portfolio.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- npm

## Engineering Guidelines

- Use TypeScript.
- Prefer simple implementations.
- Do not add dependencies unless necessary.
- Keep components reasonably small.
- Use semantic HTML.
- Maintain keyboard accessibility.
- Maintain responsive layouts.
- Do not modify unrelated files.
- Explain significant architectural changes.
- Run lint and production build after significant changes.
- Do not introduce a backend unless the feature requires one.

## Workflow

Before significant changes:
1. Inspect the relevant existing code.
2. Explain the proposed approach.
3. Make focused changes.
4. Run appropriate validation.
5. Summarize what changed.
